# Stokito

Logiciel en ligne de gestion de stock, devis, bons de livraison et factures pour les PME (https://stokito.com).

- Laravel + Livewire 3 (Volt) + Tailwind + Alpine
- Multi-sociétés, FR / AR / EN, pays : France, Maroc, Belgique, Suisse, Luxembourg, Sénégal, Côte d’Ivoire, Cameroun, Tunisie, Algérie
- Déploiement automatique depuis la branche main : voir DEPLOY.md

Code propriétaire, dépôt privé.
